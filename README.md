# Student Performance AI

## Project Overview
Student Performance AI is a machine learning project designed to predict student performance based on academic and related input data.

## Features
- Data preprocessing
- Machine learning model training
- Student performance prediction
- Simple web application interface

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## Project Structure
- app.py
- requirements.txt

## How to Run
1. Install the required packages:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
